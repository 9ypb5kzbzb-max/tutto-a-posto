TUTTO A POSTO — PROTOTIPO PWA

Contenuto:
- index.html: app demo responsive
- manifest.json: configurazione PWA
- sw.js: cache offline di base
- icon-192.png e icon-512.png: icone

Per pubblicarla con GitHub Pages:
1. Crea un repository pubblico su GitHub.
2. Carica tutti i file contenuti in questa cartella nella root del repository.
3. In Settings > Pages, scegli Deploy from a branch, branch main, folder / (root), salva.
4. Quando l'indirizzo HTTPS è pronto, aprilo in Safari su iPhone.
5. Premi Condividi > Aggiungi alla schermata Home.

Nota: prototipo dimostrativo. Non esegue pagamenti, non si collega a banche/enti e non analizza davvero i documenti. Il file selezionato resta nel browser e viene soltanto mostrato come selezionato.
